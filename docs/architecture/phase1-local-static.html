Request / Response Sequence

Step-by-step timeline of a single voice turn — from the user pressing the mic button to hearing the spoken response. Shows every message type over the WebSocket.

Local Infrastructure

All processes run on the same Windows 11 machine. Three terminal windows, three ports. Ollama runs as a background service after install.

Third-Party Stack — Phase 1 (Local)

Every external tool used in Phase 1. All free and offline after initial download.

Layer Tool What It Does Source
Frontend Next.js 14 free React framework with App Router. SSR for panels. Dev server at :3000. npm
Frontend Tailwind CSS 3 free Utility-first CSS. All UI styling. npm
Transport WebSocket (native) built-in Browser WebSocket API for audio streaming. No library needed. browser
Backend FastAPI free Python async web framework. WebSocket handlers, REST health endpoint. pip
Backend Uvicorn free ASGI server. Runs FastAPI with --reload for dev. pip
Backend pydantic-settings free Reads .env file into typed Settings class. LOCAL_MODE switch. pip
STT faster-whisper free CTranslate2-optimised Whisper. Runs on CUDA. Transcribes webm audio to text. pip
STT Whisper medium model free ~1.5GB VRAM. Auto-downloaded on first run to ~/.cache/huggingface. HuggingFace
LLM Ollama free Local LLM runner. Exposes OpenAI-compatible API at :11434. CUDA-accelerated. winget
LLM llama3.1:8b (q4_K_M) free ~5.5GB VRAM. Meta's Llama 3.1 quantised. Pulled via ollama pull. Ollama registry
TTS Piper TTS free Local neural TTS. Runs on CPU. Under 50ms latency. Outputs WAV. GitHub releases
TTS en_US-amy-medium.onnx free Piper voice model. ONNX format. ~65MB. English US female voice. HuggingFace
Database SQLite built-in File-based DB. Stores sessions and conversation history. Zero config. Python stdlib
Database SQLAlchemy free ORM layer over SQLite. Session, Message models. Async-safe. pip
HTTP client httpx free Async HTTP. Used by llm.py for Ollama streaming. Ready for Cartesia in Phase 2. pip
GPU CUDA 12.6 installed Already on machine (confirmed via nvidia-smi). Used by Whisper + Ollama. NVIDIA driver 560.94
